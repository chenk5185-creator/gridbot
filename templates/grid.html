📋 手动获取方法
  1. 1访问 app.standx.com 并连接钱包
  2. 2按 F12 打开开发者工具
  3. 3切换到 Network 标签
  4. 4刷新页面，搜索 login 请求
  5. 5复制 Response 中的 token 字段
⚠️ 手动获取的 Token 无法用于下单，仅能查询
